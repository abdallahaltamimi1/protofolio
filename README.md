# 👨‍💻 Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML5 and CSS3** to showcase my background, qualifications, technical and soft skills, projects, and contact information.

## 🌟 About The Project

This portfolio was created to present my journey as a beginner web developer and to provide a simple, clean, and responsive platform where visitors can learn more about me, explore my skills and projects, and easily get in touch with me.

The design focuses on **simplicity, responsiveness, clean structure, and user-friendly navigation** across different screen sizes.

## 📌 Sections

* 👤 **About Me** — Introduction, background, and personal information.
* 📜 **Qualifications** — Educational background and development training.
* 🛠️ **Skills** — Technical skills and soft skills.
* 📝 **Projects** — A collection of my HTML and CSS projects.
* ✉️ **Contact** — Links to my email, LinkedIn, GitHub, and WhatsApp.

## 🛠️ Technologies Used

* **HTML5** — Semantic and structured web content.
* **CSS3** — Styling, layouts, animations, and responsive design.
* **Flexbox** — Creating flexible and responsive layouts.
* **CSS Media Queries** — Adapting the website for mobile, tablet, and desktop screens.
* **Git & GitHub** — Version control and project management.

## 📱 Responsive Design

The website is designed to work across different devices:

* 📱 Mobile devices
* 📱 Tablets
* 💻 Laptops
* 🖥️ Desktop screens

CSS media queries are used to adjust layouts, font sizes, spacing, project cards, skills sections, and the footer depending on the screen size.

## 🎯 Project Goals

The main goals of this project are:

* Practice HTML and CSS fundamentals.
* Improve responsive web design skills.
* Learn how to organize a complete website into reusable sections.
* Build a professional personal portfolio.
* Practice using Git and GitHub.
* Create a foundation for future web development projects.
